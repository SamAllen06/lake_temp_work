# CSV to NetCDF Cases Script
testing/utils/acts_csv_to_ncdf_cases/

The CSV to NetCDF Cases script is used to convert a CSV file containing indices that
will be mapped to the values of the corresponding model constant to create a single 
[SampleGroup](../../../../testing/model_testing_framework/docs/src/sampling/sample_group.md) in a NetCDF file that the LakeTemperature module can run on. We use it to
convert CSV files generated by [ACTS]() to NetCDF files. 

It requires three arguments. They are: a path to a CSV file containing the indices for
the model constants, a path to the partition file that will be used to map the indices
to the actual values, and a path to where the NetCDF file should be saved.
